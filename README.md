# Aduaan™

A mobile nutrition tracking application designed to help users understand and monitor their daily nutritional intake.


## Overview

Aduaan is a student software development project focused on making nutritional tracking more accessible through a mobile application.

## Technology Stack

* **Frontend:** Flutter
* **Programming Language:** Dart
* **Platform:** Android & iOS
* **Backend:** To be determined
* **Database:** To be determined
