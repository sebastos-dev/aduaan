# Functional Requirements

This document describes the core functionalities
that Aduaan™ must provide.

## 1. User Authentication
- Users can create an account.
- Users can log into their accounts.
- Users can securely log out.

## 2. Food Logging
- Users can search for food items.
- Users can record their meals.
- Users can view their daily food records.

## 3. Nutrition Tracking
- Users can view estimated nutritional values.
- Users can monitor daily nutritional intake.
- Users can review their nutrition history.
